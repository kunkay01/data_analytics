Variable description¶

  • PassengerId passenger identification number
  • Survival survival status (0 = No; 1 = Yes)
  • Pclass passenger class (1 = 1st; 2 = 2nd; 3 = 3rd)
  • Name name
  • Sex sex
  • Age age
  • SibSp number of siblings/spouses aboard
  • Parch number of parents/children aboard
  • Ticket ticket number
  • Fare passenger fare (British pound)
  • Cabin cabin
  • Embarked port of embarkation (C = Cherbourg; Q = Queenstown; S = Southampton)

With test_size=0.50 the model is trained on fewer observations and evaluated on more test data. Compared to the original 80/20 split, the accuracy and recall change slightly. Any decrease in performance can be explained by the smaller training set (less information for the tree to learn from). Small changes are also expected due to the randomness in the train/test split.

When I increase max_depth, the classification tree becomes deeper and more complex (more nodes and splits). The model fits the training data better (higher training accuracy), but the tree also risks overfitting, because it can adapt to noise and very specific patterns in the training set. Visually, the text output and the plot show more detailed splits, while with smaller max_depth the tree is simpler and easier to interpret.

The model that includes Age and Sex_male has a higher AUC and a ROC curve that lies further above the diagonal. When I remove Age and Sex_male from the feature set, the AUC decreases and the ROC curve moves closer to the diagonal, which means the classifier is less able to distinguish between survivors and non-survivors. This shows that Age and Sex_male are very important predictors for survival in the Titanic data.
